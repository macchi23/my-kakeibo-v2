# 記事シリーズ構成案（Zenn）

状態は記事を出したら更新する（未着手 / 下書き / 公開済み）。各回の題名・タグ・公開日・URL は `articles/README.md` で管理する。

## シリーズの軸

Go 未経験者が、Claude Code と一緒に個人用の家計簿アプリを Go（Lambda）+ CDK で作る記録。
（各回の構成は、段階が進んで素材が揃ってから決める）

## 書き方のルール

- 各回を単独で読めるようにする。題名の本体は具体的な問いにし、シリーズ名は後ろに付ける。一覧や検索では題名の頭しか見えないため
- 判断の理由と、実測した数字（件数、応答時間、費用）を必ず入れる
- 自分の言葉で書く。設計判断は自分で説明できる状態で出す
- AI 利用の明記: Zenn のコミュニティガイドラインと AI コンテンツ方針（2026-03-10）では、AI 利用の明記義務はなく、生成 AI の活用は禁止されていない。正確性を確かめずに投稿することと、記事の乱造は避けるよう求められている（2026-10-27 に確認。https://zenn.dev/guideline 、https://info.zenn.dev/2026-03-10-ai-contents-guideline ）。各回の末尾で、AI に任せた範囲と確かめた範囲を一言書く
- 宣伝が主目的の投稿は規約で禁じられている。リポジトリへのリンクは記事末尾に控えめに置く
- Zenn には個人の記事を連載としてまとめる機能が無い（2026-10-27 時点）。題名の後ろにシリーズ名を付け、共通のトピックを 1 つ付け、各回で相互にリンクする
- 紹介回を最初に出す。各回の「はじめに」は短くして紹介回へリンクする
- 実装済みの内容は、`DECISIONS.md` / `setup.md` / `go/`（非公開の `notes/` も参照） から Claude Code に骨格を作らせ、自分の言葉に直す

## 公開前チェック

- AWS アカウント ID、ARN、Cognito の ID、API のエンドポイント URL、SSO の設定、メールアドレスを伏せる
- 会社の業務に触れる場合は許可を取り、抽象化する
- リポジトリを public にする前に、git の履歴に秘密情報がないかを確認する
