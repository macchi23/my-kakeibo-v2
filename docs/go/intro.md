# Go とは（basics.md の前に読む）

Python / PHP を書いたことがある人向けに、Go がどんな言語かをざっくり掴むための資料。文法の細部は [`basics.md`](basics.md)、
Python / PHP の書き方から Go を引くときは [`python-to-go.md`](python-to-go.md)。

## 1. ひとことで

**Google が作った、コンパイルして 1 つの実行ファイルにする、静的型付けの言語。** 2009 年に公開。
文法を小さく保つことを重視していて、「書き方が 1 通りに寄る」ように作られている。

| | Python / PHP | Go |
|---|---|---|
| 実行のしかた | ソースをインタプリタが読んで実行 | 先にコンパイルして実行ファイルを作り、それを実行 |
| 型 | 実行時に決まる（動的型付け） | コンパイル時に決まる（静的型付け） |
| 型の間違い | 動かしてその行に来たときにエラー | コンパイルの時点でエラー（動かす前に分かる） |
| 動かすのに要るもの | Python / PHP 本体 + ライブラリ | 実行ファイル 1 つだけ |
| 並行処理 | スレッド・asyncio など | goroutine（言語に組み込み。この家計簿ではほぼ使わない） |

Java を研修で触ったなら、「Java から class と継承と例外を取り除いて、軽くしたもの」と思うと近い。

## 2. なぜこの家計簿で Go を使うか

- Lambda との相性: 実行ファイル 1 つを置くだけで動き、起動（コールドスタート）が速く、メモリも少なくて済む
- 型のおかげで、DynamoDB のキーやユーザー ID の取り違えをコンパイラが止めてくれる（家計簿は他人のデータが混ざると困る）
- 標準ライブラリだけで HTTP サーバー・JSON・テストまで書ける。フレームワーク選びで迷わない

## 3. Python から来ると戸惑う所（先に知っておく）

1. **型を書く。** 関数の引数と戻り値には必ず型を書く。変数は `x := 1` と書けば型は推論される
   ```go
   func add(a int, b int) int { return a + b }
   ```
2. **エラーは例外ではなく戻り値。** `try/except` が無い。関数は「結果, エラー」の 2 つを返し、呼んだ側が毎回 `if err != nil` で確かめる。最初は冗長に感じるが、Go ではこれが普通
   ```go
   v, err := strconv.Atoi("12")   // Python の int("12")
   if err != nil {
       return err                 // 失敗したら呼び出し元へ返す
   }
   ```
3. **公開・非公開は名前の先頭の大文字・小文字で決まる。** `NewID` は外から使える、`newID` はパッケージの中だけ（Python の `_name` の慣習を、言語が強制する版）
4. **class が無い。** データは `struct`、振る舞いは struct に付けるメソッドで書く。継承も無い
5. **インデントではなく `{ }` でブロックを作る。** ただし整形は `gofmt` が自動で揃えるので、書き方で悩まない
6. **使っていない import や変数があるとコンパイルエラー。** 試しに書いて消し忘れると怒られる（慣れるまで地味に引っかかる）
7. **`None` / `null` の代わりに「ゼロ値」。** 宣言しただけの変数は、`int` なら `0`、`string` なら `""` が入っている

## 4. プログラムの形

```go
package main            // このファイルが属するパッケージ。実行ファイルの入口は main

import "fmt"            // 使うパッケージ（Python の import と同じ）

func main() {           // 実行するとここから始まる（Python の if __name__ == "__main__": に近い）
    name := "家計簿"
    fmt.Println("hello", name)
}
```

- 1 つのディレクトリ = 1 つのパッケージ。この家計簿なら `backend/internal/kakeibo/` が `kakeibo` パッケージ
- 実行ファイルの入口は `backend/cmd/api/main.go`（ローカル用）と `backend/cmd/lambda/main.go`（Lambda 用）

## 5. よく使う `go` コマンド

`backend/` で実行する。

| コマンド | すること | Python で言うと |
|---|---|---|
| `go run ./cmd/api` | コンパイルして、すぐ実行 | `python app.py` |
| `go build ./...` | コンパイルだけ（エラーが無いか確かめる） | （近いものは無い。型チェックの mypy が近い） |
| `go test ./internal/kakeibo/` | テストを実行 | `pytest` |
| `go vet ./...` | よくある間違いを検出 | `flake8` などの linter |
| `gofmt -w .` | 整形 | `black` |
| `go mod tidy` | 依存ライブラリを整理 | `pip` + `requirements.txt` の整理 |

## 6. エラーメッセージの読み方

コンパイルエラーは「ファイル:行:列: 内容」の形で出る。

```
internal/kakeibo/errors.go:27:2: undefined: fmtt
```

27 行目の 2 文字目に、定義されていない名前 `fmtt` がある、という意味（`fmt` の打ち間違い）。上から順に 1 つずつ直す。
