# Go の学習

このプロジェクトのバックエンドを書きながら Go を学ぶ。目標は「Go 使ったことあります（CC に書かせたけど多少わかる）」レベル。

## 進め方のルール

1. Claude が「型定義・関数シグネチャ・解説コメント・`// TODO:`」までを用意する
2. 中身は**自分で書く**。`go build` / `go vet` のエラーを読みながら直す
3. 詰まったら「ヒント」と言えば、ヒント → 部分的な答え → 完全な答え の順で出る
4. 書けたら Claude がレビューし、より Go らしい書き方があれば示す

1 回のやりとりは 1 機能・数十行程度の小刻みで進める。

最初のバックエンドファイル（P1）だけは次の順で進める:

1. Go の基本レクチャー
2. 虫食いにして自分で埋める（レビュー前に実施）
3. 間違いを修正 → レビュー → デプロイ

## ドキュメントの運用

- 新しい概念が出たら、まずこのディレクトリに書き足してから、会話では要点だけ触れる
- ターミナルで長文を読むのは辛いので、腰を据えた説明は必ずファイル側に置く
- 既存ファイルに追記できるものは追記、独立したテーマなら新規ファイルを作る
- 既に知っている言語（TypeScript）との対応表を作る（P1 で `ts-to-go.md`）

## よく使うコマンド

```sh
cd backend
go run ./cmd/api      # ローカルで API を起動
go build ./...        # ビルド（型エラーの確認）
go vet ./...          # 怪しい書き方の検出
go test ./...         # テスト
gofmt -w .            # 整形
go doc <パッケージ>   # ドキュメントを読む（例: go doc net/http.ServeMux）
```
